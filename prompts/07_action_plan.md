# Section prompt 7 — Action Plan

Build the Action Plan view.

- Generate one item per material **unfavourable** variance, per forecast flag, and per balance-sheet item more than 10% above budget (e.g. inventory).
- Columns: Issue (with $ and period), Proposed next step, Owner (role), Due date (next review meeting), Status (Open / In progress / Done), Notes.
- Status and notes are editable in the page; add an "Export CSV" button.
- Use `templates/action_plan_template.md` for wording. Every item must have an owner and a date.
