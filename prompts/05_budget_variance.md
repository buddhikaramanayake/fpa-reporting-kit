# Section prompt 5 — Budget Variance

Build the Budget Variance view.

- EBITDA bridge (waterfall): comparison EBITDA → each line's profit impact → selected EBITDA. Favourable bars and unfavourable bars use distinct colours and a legend.
- Variance table sorted by absolute profit impact with a "Material" flag. Default threshold: |impact| ≥ $50K, or |impact| ≥ $25K and |variance| ≥ 5% (confirm with the user).
- For each material line write commentary with the template. Use the monthly pattern as evidence: when did the gap open, does it persist, is one month responsible (one-off / accrual timing)?
