# Section prompt 6 — Forecast

Build the Forecast view for the current fiscal year.

- Latest Estimate (LE) = closed actuals + forecast for open months. Show the tie-out on screen.
- Table: Actual YTD, Forecast rest of year, LE, Budget, LE vs Budget, Prior year, LE vs PY for Revenue, Gross Profit, Opex, EBITDA, Net Income.
- Chart: revenue path — Actual (solid), Forecast (dashed), Budget.
- Assumption flags: for each line, compare the forecast's % vs budget for the open months with the **median** monthly % vs budget of the last three closed months. Flag lines where the forecast is ≥ 2 points more optimistic than the run-rate. Ask the owner what changes, or recommend resetting to run-rate.
